# Homebrew Tap

Whizystems [Homebrew](https://brew.sh/) tap.

## Installation

```bash
brew tap whizystems/tap
brew install rdm
```

## Available packages

| Package | macOS | Linux | Description |
|---------|-------|-------|-------------|
| [rdm](https://github.com/whizystems/redmine-cli) | ✅ | ✅ | Agent-first Redmine CLI with markdown-optimized output |
